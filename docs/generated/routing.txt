Маршрутизация моделей
=====================

[Класс задачи → модель]
plan          → claude-opus-5-5    high    Планы и архитектура: ошибка здесь стоит дороже всей сессии, поэтому самая сильная модель.
critical_adr  → claude-opus-5-5    max     Решения, которые трудно отменить (безопасность, формат данных): максимум рассуждения.
implement     → claude-sonnet-5-5  high    Код по готовому плану: Sonnet с глубоким мышлением. Дешевле Opus и надёжнее быстрого режима: меньше повторных попыток.
debug         → claude-sonnet-5-5  high    Поиск причины ошибки: нужно больше рассуждения, чем для обычного кода.
review        → claude-opus-5-5    medium  Проверка чужих правок: сильная модель находит больше ошибок.
mechanical    → claude-sonnet-5-5  low     Переименования, форматирование, тексты: думать глубоко не нужно.
summary       → claude-haiku-5-5   low     Краткие пересказы и карточки передачи: самая дешёвая модель.

[Лестница при затыке]
sonnet medium ─(2 провала)► sonnet high ─(3 провала)► opus high + карточка
граница безопасности → ревью Opus всегда
лимит Claude → Codex (если у него есть запас)
субагенты: выключены по умолчанию
