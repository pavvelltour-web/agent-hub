Архитектура
===========

[Схема]
  вы ─► hub CLI / hub ui
          │
          ▼
┌─ ядро ────────────────────────────────────────────────────────────────────────┐
│ Ядро: реестр · lock · компиляторы · скаут · загрузка инструментов · init/undo │
│ Этапы проекта и ворота                                                        │
│ Экономика и советчик                                                          │
└───────────────────────────────────────────────────────────────────────────────┘
     │ адаптеры          │ только чтение        │ запись по OK
     ▼                   ▼                      ▼
┌─ запуск и данные ─────────────────────────────┐
│ Запуск: worktree · раннер · карточка передачи │
│ Адаптеры агентов (claude, codex)              │
│ Журнал: импорт, индекс, поиск (SQLite)        │
└───────────────────────────────────────────────┘
  агенты: claude CLI · codex CLI   │   ~/.claude  ~/.codex (только чтение)   │   файлы проекта (hub.json, hub.lock.json, AGENTS.md, .hub/)

[Папки]
src/cli        hub CLI
src/server     Сервер + панель (127.0.0.1)
src/core       Ядро: реестр · lock · компиляторы · скаут · загрузка инструментов · init/undo
src/stages     Этапы проекта и ворота
src/econ       Экономика и советчик
src/run        Запуск: worktree · раннер · карточка передачи
src/adapters   Адаптеры агентов (claude, codex)
src/history    Журнал: импорт, индекс, поиск (SQLite)
src/diagram    Схемы (этот вывод)
src/lib        Общее: пути, секреты, хэш, JSONL
